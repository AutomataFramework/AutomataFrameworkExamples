# Roadmap

The one roadmap is kept in the project's shared files (`roadmap/roadmap.md`), approved and frozen by the Owner on
2026-11-27, and copied to Notion. This repo does not keep its own copy, since that file holds names that stay
private. What this repo does, slice by slice:

- **Slice 0 (setup):** the games kit, CI on GitHub's runners, the licence split and its check, the private-names
  check, and RunPod GPU runners that a fork's pull request cannot start, with one measured GPU run.
- **Slice 1a onward:** the small one-file examples (one per new function, run in CI) and the 2D and 3D samples,
  under those code names.
