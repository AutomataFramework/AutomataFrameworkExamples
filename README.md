# AutomataFrameworkExamples

Small games made with Automata Framework, and the two sample games that show what it can do.

## What you may use

- **The code is free to use.** It is under the MIT licence in [`LICENSE`](LICENSE): copy it, change it and use it in
  your own games.
- **The sample games' story, art, music and sound are not.** They are all rights reserved to their owner. Every
  folder that holds them carries a [`CONTENT-LICENSE.md`](games/CONTENT-LICENSE.md) that says so.

This is the split DOOM used: the engine is open, the game's own content is not. Make your game with the code and
bring your own content.
